# Joenell CV — Vercel

A simple, mobile-friendly static CV page using the uploaded CV image.

## Files
- `index.html` — CV webpage
- `cv.jpg` — uploaded CV image
- `qr-code.png` — QR code intended to open the production URL

## Deploy with GitHub + Vercel

1. Create a new GitHub repository named **joenell-cv**.
2. Upload all files in this folder to the repository.
3. Import the repository into Vercel.
4. Set the project name to **joenell-cv** if that name is available.
5. Deploy.

Vercel supports Git-based deployments, and pushes to the production branch can trigger new deployments.

## QR code

The included QR code points to:

https://joenell-cv.vercel.app

For the QR code to work exactly as supplied, the deployed Vercel project should use that URL. If Vercel assigns a different URL, generate a new QR code for the final production URL.

## Privacy note

The uploaded CV image contains contact details and a street address. Because this page is intended to be publicly accessible, make sure you are comfortable publishing those details online.
